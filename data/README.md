# Dados

Este diretório contém o gerador e os arquivos de dados sintéticos usados nos experimentos.

## Gerar os dados

Na raiz do repositório, execute:

```bash
python data/generate_data.py
```

Os arquivos CSV serão criados em `data/generated/`. A geração usa uma semente fixa para facilitar a reprodução dos experimentos.

## Observação

Os dados são artificiais e foram criados exclusivamente para desenvolvimento e validação técnica. Não representam pessoas, empresas ou operações reais. Os arquivos gerados não são versionados no Git.
