# 📊 Dados sintéticos

Os arquivos CSV desta pasta são gerados localmente pelo script `generate_data.py` e não são versionados.

## Gerar dados

Na raiz do projeto:

```bash
python data/generate_data.py
```

O script cria:

- `customers.csv`
- `restaurants.csv`
- `couriers.csv`
- `orders.csv`
- `payments.csv`
- `reviews.csv`

Todos os registros são fictícios.
